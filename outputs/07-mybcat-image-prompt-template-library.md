# MyBCAT Image Prompt Template Library

Use these templates to create future MyBCAT image prompts. Each template is self-contained: copy one template, fill the fields in {{DOUBLE BRACES}}, and paste it into ChatGPT or another reasoning-capable image generation tool. If exact typography or text accuracy matters, generate the image with minimal text and add final copy in a design tool.

## Shared brand context embedded in every template

MyBCAT, My Business Care Team, provides centralized patient access operations for healthcare practices and multi-location groups. It answers inbound patient calls, schedules appointments in EHR/PMS systems, supports intake, recall, no-show recovery, front-desk workflows, and reporting. It is a Remote Hospitality Center, Patient Acquisition Engine, and Patient Acquisition + Practice Intelligence OS, not a commodity VA agency, generic call center, or AI receptionist. The visual brand should feel calm, credible, operational, healthcare-specific, and proof-forward.

Visual system: pale blue-gray/off-white backgrounds, large rounded cards, dark navy headings, deep teal buttons and system accents, muted gold for metrics, aqua for checkmarks and tiny indicators, and limited purple/blue/cyan only near logo-like circular signal motifs. Typography should be modern B2B SaaS sans-serif, bold for headlines and legible for captions. Avoid red emergency colors, robot receptionists, headset stock-photo walls, generic offshore staffing tropes, cartoon doctors, stethoscope clichés, heavy sci-fi AI imagery, and any PHI or real patient data.

# Usage guide

1. Pick the template matching your asset type.
2. Fill only the fields in {{DOUBLE BRACES}}.
3. Paste the completed prompt into ChatGPT or another image-generation tool.
4. If exact text matters, ask for the image with text-safe blank areas and add final text manually.
5. Reject generic outputs aggressively. Useful rejection notes: “too generic call center,” “too AI/robotic,” “too clinical/hospital,” “not enough patient-access operations,” “not enough MyBCAT teal/navy/gold card system,” or “too much clutter.”
6. When one template consistently produces good assets, save the successful prompt and example output as a new MyBCAT visual pattern.
